# Begrippenlijst

Engelse termen helpen officiële documentatie lezen. Dit zijn korte leerdefinities, geen gegarandeerde officiële examenvertalingen.

| Term | Nederlandse uitleg |
|---|---|
| Output | Opgeleverd product of resultaat. |
| Outcome | Verandering in gebruik, gedrag of werking. |
| Benefit | Meetbaar voordeel van een verandering. |
| Scope | Wat binnen en buiten de opdracht valt. |
| Baseline | Vastgelegde referentie voor vergelijking en wijzigingen. |
| Milestone | Belangrijk toets- of oplevermoment. |
| Dependency | Afhankelijkheid van ander werk, informatie of een partij. |
| Critical path | Langste afhankelijkheidsketen die de einddatum bepaalt. |
| Risk | Onzekere gebeurtenis die doelen kan beïnvloeden. |
| Issue | Actuele situatie die aandacht of een besluit vraagt. |
| Assumption | Aanname die nog validatie nodig heeft. |
| RAID | Risks, Assumptions, Issues, Dependencies; leg lokale varianten vast. |
| Stakeholder | Persoon of groep met belang, invloed of impact. |
| Tolerance | Afgesproken afwijkingsruimte binnen een mandaat. |
| Acceptance criteria | Toetsbare voorwaarden voor acceptatie. |
| Definition of Done | Beschrijving van vereiste kwaliteit van het Increment in Scrum. |
| Product Goal | Langetermijndoel voor het Scrum-product. |
| Sprint Goal | Eén samenhangend doel voor de Sprint. |
| WIP | Work in Progress: gestart maar nog niet afgerond werk. |
| Cycle time | Verstreken tijd van start tot afronding volgens gekozen meetgrenzen. |
| Incident | Verstoring van een dienst of vermindering van kwaliteit. |
| Problem | Oorzaak of mogelijke oorzaak van één of meer incidenten. |
| Adoption | Daadwerkelijk gebruiken van de verandering in het werk. |
| Benefit owner | Verantwoordelijke voor het volgen en realiseren van een benefit. |

| Aanvullende term | Uitleg |
|---|---|
| Governance | Afspraken over sturing, bevoegdheden en verantwoording. |
| UAT | User Acceptance Testing: toetsen door gebruikers tegen afgesproken acceptatie. |
| Change control | Beoordelen en besluiten over wijzigingen aan projectafspraken. |
| Change enablement | Passende beoordeling en beheersing van veranderingen aan diensten. |
| Organisational change | Verandering van werk, gedrag, processen en organisatie. |
| Lead time | Tijd van een afgesproken verzoekmoment tot levering; definieer meetgrenzen. |
| Throughput | Aantal afgeronde items per periode. |
| Roadmap | Richting en verwachte ontwikkeling; precisie hangt af van onzekerheid. |
| Programme | Samenhangende veranderinitiatieven sturen op gezamenlijke benefits. |
| Portfolio | Investeringen en initiatieven kiezen en balanceren. |
